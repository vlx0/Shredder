# Shredder

Надёжное удаление файлов для Windows: содержимое перезаписывается случайными данными, затем файл удаляется.

Не путать с корзиной — восстановить обычными средствами после Shredder нельзя.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

Часть серии **365 дней open source** · неделя «Безопасность» · день 4.

---

## Возможности

- Выбор файлов и папок
- 1 / 3 / 7 проходов перезаписи
- Переименование перед удалением (чтобы не осталось старого имени)
- Тёмный интерфейс

## Установка

```powershell
git clone https://github.com/vlx0/Shredder.git
cd Shredder
.\setup.bat
```

Или:

```powershell
python -m pip install -r requirements.txt
pythonw run_shredder.pyw
```

## Важно

- На SSD многопроходная перезапись не гарантирует физическое стирание блоков (TRIM), но файл всё равно становится недоступен через обычное восстановление.
- Перед уничтожением проверьте список дважды — отмены нет.
